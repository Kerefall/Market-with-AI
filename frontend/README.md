# Фронтенд маркетплейса

Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui и ESLint.

## Запуск

Команды выполняются из этой папки. Используйте Node.js из `.nvmrc` и npm 10.9.2.

```sh
nvm use
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Изменения исходников отображаются автоматически.
Остановить сервер в терминале: Ctrl+C. Для первого запуска переменные окружения не нужны.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
```

Для проверки собранной версии сначала остановите dev-сервер и выполните `npm run start`.

## Основные файлы

- В `src/app/page.tsx` настроен переход в кабинет продавца.
- В `src/app/seller/layout.tsx` собраны шапка, меню и область содержимого кабинета.
- В `src/app/seller/` находятся страницы кабинета, в `src/app/catalog/` находятся страницы витрины.
- В `src/components/ui/` лежат общие компоненты интерфейса.
- В `src/app/layout.tsx` определены общий layout и метаданные.
- В `src/app/globals.css` подключён Tailwind и заданы глобальные стили.
- В `next.config.ts` заданы настройки Next.js. Автоматическое создание `AGENTS.md` отключено.

## Кабинет продавца

При открытии `/` приложение переходит в раздел «Магазин» на `/seller`.
Остальные разделы: `/seller/products`, `/seller/inventory`, `/seller/orders`,
`/seller/analytics`, `/seller/promotions`, `/seller/assistant`.

Разделы кабинета взяты со слайда 3 командной презентации: «Магазин», «Товары»,
«Склад», «Заказы», «Аналитика», «Продвижение». ИИ-помощник описан на слайде 4.

Меню переключает страницы внутри общего layout. На узком экране оно раскрывается
кнопкой «Разделы кабинета».

В кабинете можно редактировать профиль магазина и товары. Опубликованные товары
видны на витрине `/catalog`. Данные демо сохраняются в браузере. Формы входа
и регистрации выполняют локальную проверку полей и ждут подключения к API.
